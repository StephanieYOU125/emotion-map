# 情緒地圖 Emotion Map

一個以「愉快程度（valence）」與「身體能量／喚起程度（arousal）」整理 72 種情緒與相關心理狀態的互動象限圖。

## 功能

- 72 種情緒與心理狀態
- 12 組主題分類
- 依愉快度與能量呈現象限位置
- 中文情緒搜尋與分類篩選
- 點選情緒查看分類及身心狀態
- 72 個立體情緒角色圖鑑，點擊可放大閱讀
- 可安裝到手機或電腦的個人 PWA
- 第一次載入後可離線閱讀完整內容
- 六步驟情緒處理流程
- 12種「情緒衝動 → 有利行動」轉化示例
- 僅儲存在目前裝置的三分鐘情緒操作卡
- 響應式版面與鍵盤操作支援
- 無框架、無建置步驟的純靜態網站

## 使用方式

直接以瀏覽器開啟 `index.html`，或使用 Vite：

```bash
npm install
npm run dev
```

正式建置：

```bash
npm run build
```

## 安裝成個人 App

PWA 必須透過 HTTPS 網址開啟。網站發布後：

- iPhone／iPad：使用 Safari 開啟，點「分享」→「加入主畫面」。
- Android／電腦：使用 Chrome 或 Edge，點網站內的「安裝 App」或瀏覽器安裝選單。

第一次完整載入後，Service Worker 會快取網站與 12 張角色圖，供離線閱讀。


## 關於象限位置

圖中的位置是協助理解的近似值，不是臨床診斷或唯一標準。同一種情緒可能因情境、強度、個人經驗與文化而移動。

部分詞彙（例如冷靜、性慾、歸屬感）較接近心理狀態、動機或關係經驗；在本專案中，它們被一併收錄為可辨識的內在經驗。

## 隱私

網站不收集或傳送使用者資料。情緒操作卡使用瀏覽器的 `localStorage` 儲存在目前裝置；按下「清除操作卡」即可刪除。
