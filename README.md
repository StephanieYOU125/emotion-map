# 情緒地圖 Emotion Map

一個以「愉快程度（valence）」與「身體能量／喚起程度（arousal）」整理 72 種情緒與相關心理狀態的互動象限圖。

## 功能

- 72 種情緒與心理狀態
- 12 組主題分類
- 依愉快度與能量呈現象限位置
- 中文情緒搜尋與分類篩選
- 點選情緒查看分類及身心狀態
- 六步驟情緒處理流程
- 12種「情緒衝動 → 有利行動」轉化示例
- 不儲存資料的三分鐘情緒操作卡
- 響應式版面與鍵盤操作支援
- 無框架、無建置步驟的純靜態網站

## 使用方式

直接以瀏覽器開啟 `index.html`，或使用 Vite：

```bash
npm install
npm run dev
```

正式建置：

```bash
npm run build
```

## 關於象限位置

圖中的位置是協助理解的近似值，不是臨床診斷或唯一標準。同一種情緒可能因情境、強度、個人經驗與文化而移動。

部分詞彙（例如冷靜、性慾、歸屬感）較接近心理狀態、動機或關係經驗；在本專案中，它們被一併收錄為可辨識的內在經驗。
